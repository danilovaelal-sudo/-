# Таблица умножения — играй и учись!

Яркое интерактивное веб-приложение для детей, которое помогает выучить таблицу умножения через просмотр, тренажёр с озвучкой и систему наград.

## Возможности

- **Таблица умножения** — интерактивная сетка 1×1…10×10 с подсветкой строки/столбца, звуком и голосовой озвучкой примера при клике.
- **Тренажёр (квиз)** — выбор чисел для тренировки, вопросы с 4 вариантами ответа, мгновенная обратная связь со звуком и озвучкой, «умный» выбор чисел с упором на те, где ребёнок чаще ошибается.
- **Прогресс и награды** — звёзды мастерства по каждому числу (0–3), серии верных ответов, бейджи за достижения, сброс прогресса.
- **Звук и озвучка** — звуковые эффекты (WebAudio, без файлов) и голосовое произношение примеров через Web Speech API, с общим переключателем звука.
- **Сохранение прогресса** — локально в браузере (localStorage), без сервера и регистрации.

## Технологии

React 18 + TypeScript + Vite, обычный CSS с анимациями (без UI-библиотек).

## Запуск

```bash
npm install
npm run dev
```

Откроется адрес из вывода Vite (обычно http://localhost:5173).

## Сборка

```bash
npm run build
npm run preview
```

## Структура проекта

```
src/
  state/      — типы, localStorage-хранилище прогресса, React-контекст
  engine/     — генератор вопросов квиза, правила мастерства и наград
  audio/      — звуковые эффекты и озвучка (Web Speech API)
  components/
    layout/   — шапка, нижняя навигация
    home/     — главный экран
    table/    — интерактивная таблица умножения
    quiz/     — тренажёр (настройка, вопрос, варианты ответа, фидбек)
    progress/ — экран прогресса, статистика, бейджи
    shared/   — переиспользуемые UI-компоненты (кнопки, карточки, маскот, конфетти)
```
