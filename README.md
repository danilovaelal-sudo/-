# УМНО — интерактивная лаборатория чисел

Веб-приложение для детей 7–10 лет, которое учит таблице умножения через визуальные группы, короткие уроки и постепенное открытие таблиц — от простых (×2, ×5, ×10) к сложным.

## Возможности

- **Сегодня** — главный экран сам предлагает следующий шаг: текущий урок, что повторить, краткий обзор прогресса.
- **Учиться** — таблицы открываются по порядку (по умолчанию: 2, 5, 10, 3, 4, 6, 9, 7, 8; в настройках можно переключить на школьный порядок). Каждый урок объясняет умножение через ряды световых ячеек, затем даёт 5 разных типов заданий: выбор ответа, ввод с клавиатуры, сборка групп, заполнение пропуска, соединение примера с ответом.
- **Вся таблица** — полный справочник 1–10 с подсветкой строки/столбца, симметричных примеров (3×4 и 4×3) и визуальной моделью по клику.
- **Тренироваться** — трудные примеры, смешанная тренировка или свободный выбор таблиц; 5/10/15 заданий без таймера.
- **Прогресс** — состояние по каждой таблице (новый → изучается → знакомо → уверенно / нужно повторить), список трудных примеров, история занятий, спокойный счётчик серии дней.
- **Пикс** — собственный SVG-помощник (не эмодзи, не готовый персонаж), реагирует на верный ответ, ошибку и подсказку.
- **Обратная связь на ошибку** — без «неверно» и красного экрана: мягкая подсветка, визуальная модель примера, повторная попытка; пример уходит в список повторения.
- **Звук** — короткие синтезированные эффекты (WebAudio, без файлов) для нажатия, верного ответа, подсказки и окончания урока; отдельно можно включить озвучивание примеров в разделе «Вся таблица» (Web Speech API, с проверкой поддержки браузера).
- **Прогресс сохраняется** локально в browser (localStorage), без сервера и регистрации; настройки позволяют сбросить весь прогресс с подтверждением.

## Технологии

React 18 + TypeScript + Vite, обычный CSS с переменными дизайн-системы (без UI-библиотек), Vitest для модульных тестов.

## Запуск

```bash
npm install
npm run dev
```

Откроется адрес из вывода Vite (обычно http://localhost:5173).

## Тесты

```bash
npm run test
```

## Сборка

```bash
npm run build
npm run preview
```

## Публикация на GitHub Pages

При пуше в ветку `claude/multiplication-table-app-gr0c1l` workflow `.github/workflows/deploy.yml` собирает проект и публикует `dist/` на GitHub Pages. Приложение доступно по адресу `https://<пользователь>.github.io/-/`.

## Структура проекта

```
src/
  config/       — константы приложения (название «УМНО», имя помощника «Пикс»)
  data/         — учебные данные (диапазоны таблиц, порог открытия следующей таблицы)
  state/        — типы, localStorage-хранилище прогресса v2, React-контекст
  engine/       — генерация вариантов ответа, состояние примеров, план урока, план тренировки
  audio/        — звуковые эффекты и озвучивание (Web Speech API)
  components/
    icons/      — единый набор SVG-иконок
    brand/      — логотип
    pix/        — цифровой помощник Пикс
    layout/     — шапка, нижняя навигация, обёртка приложения
    today/      — главный экран «Сегодня»
    learn/      — «Учиться» (карточки таблиц)
    fulltable/  — «Вся таблица» (справочник)
    lesson/     — движок урока: модель умножения, уравнение, подсказка, обратная связь, 5 типов заданий
    practice/   — «Тренироваться» (настройка и сессия тренировки)
    progress/   — экран прогресса
    settings/   — настройки
    shared/     — переиспользуемые UI-компоненты (кнопки, карточки, клавиатура, диалог подтверждения)
```
